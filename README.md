### 🛡️ จุดเด่นด้าน "ความปลอดภัย" (Security & PDPA)
1. **Password Security**: เลิกระบบจัดเก็บรหัสผ่านแบบข้อความธรรมดา (Plain text) ที่เคยอยู่ใน Excel ชีต `Account` โดยเปลี่ยนมาใช้การเข้ารหัสแบบ **Argon2id / bcrypt**
2. **Role-Based Access Control (RBAC)**: รองรับการแบ่งสิทธิ์ตามหน่วยงาน
   - **Admin สสอ.เทพา**: ดูภาพรวมทุกตำบล ควบคุมนโยบายและส่งออกรายงานอำเภอ
   - **รพ.เทพา**: บันทึกเคสแรกรับ (IPD/OPD) บันทึกผลแล็บ CBC และ Dengue Rapid Test
   - **รพ.สต. ในพื้นที่ (เช่น รพ.สต.เกาะสะบ้า, รพ.สต.ลำไพล ฯลฯ)**: รับการแจ้งเตือน ลงสำรวจลูกน้ำยุงลาย และบันทึกการพ่นสารเคมี
3. **Data Masking**: มีสวิตช์เปิด-ปิดการพรางข้อมูลระบุตัวตนผู้ป่วย (ชื่อ-นามสกุล, เบอร์โทรศัพท์) ตามกฎหมาย PDPA
4. **Audit Trail**: บันทึกประวัติการเข้าถึงข้อมูลผู้ป่วยทุกครั้ง (User, Action, Timestamp, IP)

### 📱 จุดเด่นด้าน "การเข้าใช้งานง่าย" (Ease of Use & Fieldwork)
1. **Step-by-Step Wizard (5 ขั้นตอน)**: ปรับฟอร์มจากเดิมที่มี 133 คอลัมน์ในแถวเดียว ให้กลายเป็นขั้นตอนที่ชัดเจน กรอกสะดวกบนสมาร์ทโฟน
2. **Auto-Calculations**:
   - คำนวณกลุ่มอายุอัตโนมัติจากอายุปี
   - คำนวณค่า **CI บ้านผู้ป่วย (%)** อัตโนมัติ
   - คำนวณค่า **HI (%)** และ **CI 100 เมตร (%)** อัตโนมัติ พร้อมประเมินระดับความเสี่ยง (เขียว/เหลือง/แดง)
3. **One-Click GPS Capture**: กดปุ่มดึงพิกัดละติจูด/ลองจิจูดจากชิป GPS ของมือถือได้ทันที
4. **ระบบติดตามมาตรการ 3-3-1**:
   - แจ้งเตือนเคสใหม่ภายใน 3 ชม.
   - พ่นสารเคมี ULV ควบคุมยุงลายตัวแก่ภายใน 1 วัน (24 ชม.)
   - สอบสวนโรคและสำรวจลูกน้ำรอบ 100 ม. ภายใน 3 วัน
5. **Print to PDF (ตรงตามแบบฟอร์มเดิม 100%)**:
   - สามารถกดปุ่ม **"พิมพ์รายงาน / Export PDF"** เพื่อพิมพ์แบบสอบสวนโรคราชการตามรูปแบบในไฟล์ `2026.pdf` และ `ด.ญ.นารีรัตน์ รอดเซ็น.pdf` ได้ทันที

### 🛡️ นโยบายการแยกสิทธิ์ข้อมูลผู้ป่วยระดับ รพ.สต. (PDPA Data Isolation)
เพื่อปฏิบัติตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA) สำหรับข้อมูลสุขภาพที่มีความอ่อนไหวสูง (Sensitive Health Data):
1. **สิทธิ์ระดับอำเภอ (สสอ.เทพา / รพ.เทพา):**
   - มีสิทธิ์ดูข้อมูลผู้ป่วยและสถิติภาพรวมทุกตำบล ทุก รพ.สต. ทั่วทั้งอำเภอเทพา เพื่อใช้ในการวางแผน ควบคุมการระบาด และส่งต่อเคส
2. **สิทธิ์ระดับพื้นที่ รพ.สต. (เช่น รพ.สต.เกาะสะบ้า, รพ.สต.ลำไพล, รพ.สต.ท่าไทร ฯลฯ):**
   - **แยกสิทธิ์เด็ดขาด:** เจ้าหน้าที่ของ รพ.สต. แต่ละแห่งจะมองเห็น จัดการ และออกรายงานได้ **เฉพาะผู้ป่วยในเขตรับผิดชอบของ รพ.สต. ตนเองเท่านั้น**
   - ไม่สามารถเข้าถึงหรือค้นหาประวัติผู้ป่วยของ รพ.สต. อื่นได้
   - ตัวชี้วัด KPI และแดชบอร์ดติดตามมาตรการ 3-3-1 จะคำนวณเฉพาะตัวเลขในเขตความรับผิดชอบของ รพ.สต. นั้นโดยอัตโนมัติ
   - มีป้ายแจ้งเตือน **"ขอบเขตข้อมูล: เฉพาะพื้นที่ [ชื่อ รพ.สต.]"** แสดงอยู่ด้านบนหน้าจออย่างชัดเจนตลอดการใช้งาน

### 🔑 ระบบเข้าใช้งานและแก้ไขรหัสผ่านใหม่ (User Login & Password Migration)
ระบบได้นำข้อมูลบัญชีเจ้าหน้าที่เดิมทั้ง 34 ท่านจากไฟล์ Excel `Dengue_Report.xlsx` มาไว้บนแพลตฟอร์มใหม่ โดยมีขั้นตอนการใช้งานจริงดังนี้:

   - คลิกปุ่ม **"สลับผู้ใช้ / เข้าสู่ระบบ"** ที่มุมขวาบน
   - เลือกรายชื่อตนเอง หรือกรอกเบอร์โทรศัพท์ (Username)
   - กรอกรหัสผ่านเริ่มต้นเดิมจากไฟล์ Excel
2. **การเปลี่ยนรหัสผ่านเพื่อเปิดใช้งานบัญชี (First-Time Activation):**
   - เมื่อล็อกอินด้วยรหัสผ่านเดิม ระบบจะแจ้งเตือนให้ตั้งรหัสผ่านใหม่ทันที
   - กำหนดรหัสผ่านใหม่ส่วนบุคคลอย่างน้อย 6 ตัวอักษร
   - ระบบจะบันทึกรหัสผ่านใหม่ลงฐานข้อมูล Supabase และเปลี่ยนสถานะเป็น **`🟢 ใช้งานรหัสใหม่แล้ว (Activated)`**
   - ครั้งถัดไป เจ้าหน้าที่จะสามารถใช้รหัสผ่านใหม่นี้ในการเข้าใช้งานได้ตลอดไป
3. **การตรวจสอบสถานะรหัสผ่านโดย Admin:**
   - ที่แท็บ **"ความปลอดภัย & สิทธิ์"** มีตารางติดตามสถานะของเจ้าหน้าที่ทั้ง 34 ท่าน ว่าใครเปลี่ยนรหัสผ่านใหม่แล้วบ้างแบบเรียลไทม์
